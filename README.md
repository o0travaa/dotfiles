# dotfiles

My personal custom Hyprland environment configured purely in Lua.

## System Features
* Window Manager: Hyprland (Lua config)
* Locker: Hyprlock
* Terminal: Alacritty
* Shell: Fish
* Bar: Waybar
* Launcher: Wofi
* Logout Menu: Wlogout
* Screenshots: Grim + Wl-clipboard

## Installation

```bash
git clone https://github.com/o0travaa/dotfiles.git
cd dotfiles
chmod +x install.sh
./install.sh
```
